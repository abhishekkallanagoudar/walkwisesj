# Expo HAS CHANGED

Read the exact versioned docs at https://docs.expo.dev/versions/v54.0.0/ before writing any code.

This project targets SDK 54 deliberately, not the latest SDK. iOS Expo Go is
frozen at 54 (App Store build 54.0.2, Sept 2025), so SDK 55+ cannot run on a
physical iPhone via Expo Go. Do not upgrade the SDK without first moving to a
development build.
